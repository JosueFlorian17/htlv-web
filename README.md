# RIII-HTLV - Red Internacional de Investigación e Innovación en HTLV

Plataforma digital para la Red Internacional de Investigación e Innovación en HTLV (RIII-HTLV), integrando repositorio científico, áreas de investigación, recursos educativos, convocatorias y foro comunitario.

## Stack Tecnológico

- **Frontend**: Next.js 16 (App Router, Turbopack), React 19, Tailwind CSS v4
- **Backend**: Node.js, Express
- **Base de Datos**: PostgreSQL
- **Despliegue**: Vercel
